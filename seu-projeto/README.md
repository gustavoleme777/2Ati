
Lista de Tarefas - AV1

Instruções rápidas:

- Estrutura: `index.html`, `css/style.css`, `js/script.js`
- Rodar local: abra o PowerShell, entre em `seu-projeto` e execute:
	- cd "./seu-projeto"
	- python -m http.server 8000
	- Abrir: http://localhost:8000

Testes que o professor verificará:
- Adicionar tarefa: digitar texto e clicar em + (não aceita vazio)
- Validação: usa `trim()` e exibe mensagem no DOM
- Remover: clicar sobre uma tarefa para removê-la
